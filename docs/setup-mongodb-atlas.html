🍠 MongoDB Atlas 設定精靈

照順序完成每一步，最後會自動產生可貼到 Render 的 MONGODB_URI。約 10–15 分鐘。

1 註冊 MongoDB Atlas（免費）

點下方按鈕開啟官網，用 Google 或 Email 註冊。

開啟 Atlas 註冊頁 →

2 建立免費資料庫叢集

  • 首頁點 Build a Database（或「+ Create」）
  • 選 M0 FREE → Continue
  • Provider 選 AWS，Region 選 Singapore (ap-southeast-1) 或 Tokyo
  • Cluster Name 可維持 Cluster0 → Create Deployment
  • 等待 1–3 分鐘直到狀態為 Active

3 建立資料庫帳號

  • 若跳出建立使用者：Username 填 sweetpotato_admin
  • 點 Autogenerate Secure Password → 複製密碼貼到下方
  • 或左側 Database Access → Add New Database User → Password 方式
  • 權限選 Atlas admin 或 Read and write to any database

4 允許 Render 連線

  • 左側 Network Access → Add IP Address
  • 選 ALLOW ACCESS FROM ANYWHERE（會顯示 0.0.0.0/0）
  • Confirm
開啟 Network Access →

5 取得叢集網址

  • 左側 Database → 你的叢集 → Connect
  • 選 Drivers → 複製連線字串中 @ 後面、/ 前面的部分
  • 例如：cluster0.xxxxx.mongodb.net

6 複製完整 MONGODB_URI

下方已依專案自動加上資料庫名稱 panshi，請整段複製：

請先完成步驟 3、5 的欄位

7 貼到 Render

  • 開啟 Render → 服務 sweetpotato-api → Environment
  • 新增變數：Key = MONGODB_URI，Value = 上一步複製的整段
  • 按 Save Changes（會自動重新部署 1–3 分鐘）
開啟 Render 控制台 →

8 確認連線成功

成功時應顯示 mongodbConnected: true。然後到 訂單後台 按「重新載入訂單」。
